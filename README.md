## 🕹️ User Operations Manual

### Streaming a Movie or TV Show
1. Open **Home** or **Catalog** and select your title.
2. Click **Play Now** on the Media Details page.
3. If a mirror buffers, click any pill from **Server 01** to **Server 10** above the player.
4. For series, pick your season and episode directly from the episode drawer below the video.

### Managing Playlists & Liked Songs
1. Head to the **Music** page via the top navigation bar.
2. Search any song, artist, or YouTube query.
3. Click the **Heart icon** to add to your favorites. Clicking it again triggers the **Confirmation Alert Modal** to safeguard your library.
4. Click **+ Add to Playlist** to add songs to existing playlists or create a new playlist.

### Selecting Holographic Themes & Avatars
1. Go to **Profile**.
2. Under **Dashboard Theme**, select any of the 8 animated canvas themes. Your theme preference saves automatically to your account.
3. In **Avatar Studio**:
   - Search character names or anime/manga titles (e.g. `Koharu from Sato san`, `Yota Ramparts of Ice`, `Miki`).
   - Switch between `All Media`, `Anime Only`, or `Manga Only`.
   - Browse 1,000+ 3D glossy WhatsApp/Apple reaction emojis.
   - Enter an AI prompt to generate an entirely unique custom avatar.

## 🚀 Quick-Start Installation

### 1. Prerequisites
* **Node.js**: `v18.0.0` or higher ([Download Node.js](https://nodejs.org/))
* **MySQL Server**: Running on port `3306` (e.g. via **XAMPP**, **WAMP**, or standalone MySQL 8)
* **TMDB API Key**: Free key from [The Movie Database](https://developer.themoviedb.org/docs)

### 2. Database Initialization
Start your MySQL server and run:
```sql
CREATE DATABASE syncstream_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
> [!NOTE]
> All tables (`users`, `watchlist`, `playlists`, `playlist_songs`, `favorite_songs`, `rooms`) are auto-created when the backend server boots up!

### 3. Backend Setup
```bash
# Navigate to server directory
cd server

# Install dependencies
npm install

# Create environment configuration
cp .env.example .env
```

Configure `server/.env`:
```env
PORT=5000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASS=
DB_NAME=syncstream_db
JWT_SECRET=your_super_secret_jwt_key
```
